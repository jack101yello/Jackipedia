# Pre-Sheaf

A pre-sheaf is a [[Contravariant Functor|contravariant]] [[Set-Valued Functor|set-valued]] [[Functor|functor]]. That is to say, a pre-sheaf $F$ on a [[Category|category]] $C$ is a functor $F: C^{\text{op}} \to \text{Set}$.

## Sheaves

Let $X$ be a set and $F: \mathcal{O}(X)^{\text{op}} \to \text{Set}$ be a pre-sheaf on the [[Poset Category|poset category]] of $X$, $\mathcal{O}(X)$. $F$ is a sheaf if it preserves all [[Covering|covering]] [[Colimit|colimits]].
