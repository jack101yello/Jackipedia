# Open Set

In [[Topology|topology]], an open subset on a topological space $(X, \mathcal{T})$ is an element of the topology $\mathcal{T}$ on that space. Its complement is called a [[Closed Set|closed set]].

## Category Theory

In [[Category Theory]], one can construct a [[Functor|functor]] from the category of topological spaces to [[The Category of Sets|the category of sets]] such that every topological space is mapped to the set of its open subsets.
